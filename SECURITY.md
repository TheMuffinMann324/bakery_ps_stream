# Reporting a security issue

Use [GitHub private vulnerability reporting](https://github.com/TheMuffinMann324/bakery_ps_stream/security/advisories/new). Include the app version, Windows version, and enough information to understand the issue. Remove pairing keys, PINs, account IDs, and private network details from logs or attachments.

Report an issue isolated to a dependency to its upstream maintainers. For libchiaki, see the [chiaki-ng security policy](https://github.com/streetpea/chiaki-ng/security/policy).
